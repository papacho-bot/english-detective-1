# 함께하는 영어 탐정 🔎

**Little English Detectives — 문맥 속에서 `take part in`의 뜻을 찾아보는 짧은 영어 학습 활동**

초등학교 5–6학년 영어 학습자가 여섯 가지 상황을 읽고, `take part in`이 **“참여하다”**라는 뜻임을 익히는 웹 앱입니다. HTML, CSS, vanilla JavaScript를 하나의 `index.html`에 담아, 별도의 설치나 로그인 없이 실행할 수 있습니다.

## 학습 설계

| 설계 조건 | 앱의 구성 |
| --- | --- |
| 하나의 아동 학습자 집단 | 초등학교 5–6학년 영어 학습자 |
| 하나의 학습 문제 | 여러 단어로 이루어진 표현을 단어별로 해석하여 전체 의미를 이해하기 어려움 |
| 하나의 명확한 목표 | 새로운 상황에서도 `take part in`의 의미를 알아보기 |
| 5–10분 활동 | 여섯 가지 상황을 읽고 답과 피드백 확인하기; 시간 제한은 없음 |
| 1–2가지 학습자 행동 | 뜻 선택하기, 피드백을 읽고 다음 상황으로 이동하기 |
| 하나의 피드백 규칙 | 첫 오답에는 힌트와 재도전, 두 번째 오답에는 정답과 설명 |
| 1–2가지 양식 | 텍스트와 내장 SVG 그림; 의미 추론은 텍스트 중심 |
| 하나의 실행 파일 | 스타일과 스크립트를 포함한 `index.html` |

## 활동 내용

모든 문항은 같은 목표 표현을 서로 다른 상황에서 다룹니다.

| 순서 | 상황 | 목표 표현 |
| --- | --- | --- |
| 1 | 학교 운동회 | take part in the race |
| 2 | 미술 시간 | take part in the art activity |
| 3 | 공원 청소 | take part in the park clean-up |
| 4 | 학교 연극 | take part in the school play |
| 5 | 과학 퀴즈 | take part in the science quiz |
| 6 | 독서 모임 | take part in the reading club |

1–5번은 한국어 상황 설명과 영어 문장을 제공합니다. 6번은 한국어 상황 설명 없이 영어 문장을 제시하여 같은 표현의 의미를 새로운 문맥에서 알아보도록 합니다. 다만 안내, 선택지, 힌트는 한국어로 제공됩니다.

## 사용 방법

1. **탐정 활동 시작하기**를 누릅니다.
2. 상황과 영어 문장을 읽고, 세 가지 선택지 중 알맞은 뜻을 고릅니다.
3. 피드백을 확인합니다. 첫 응답이 틀렸다면 힌트를 읽고 다른 답을 한 번 선택합니다.
4. 문항이 끝나면 **다음 상황**으로 이동합니다.
5. 마지막 문항 후 **결과 확인하기**를 눌러 표현의 뜻과 학습 결과를 확인합니다.

완료 화면의 **처음부터 다시 해보기**를 누르면 결과를 초기화하고 다시 시작합니다.

## 피드백 방식

| 응답 | 앱의 반응 |
| --- | --- |
| 첫 시도 정답 | 정답 확인과 짧은 설명을 보여주고 문항 완료 |
| 첫 시도 오답 | 정답을 공개하지 않고 문맥 힌트 제공; 선택한 오답은 비활성화하고 한 번 재도전 허용 |
| 재도전 정답 | 정답 확인과 짧은 설명을 보여주고 문항 완료 |
| 재도전 오답 | 정답과 짧은 설명을 보여주고 문항 완료 |

완료된 문항은 모든 선택지가 비활성화되고 정답이 강조됩니다. 학습자가 피드백을 읽은 뒤 직접 다음 문항으로 이동합니다.

결과 화면에는 다음 세 항목을 표시합니다.

- 처음에 맞힌 상황 수
- 힌트 후 맞힌 상황 수
- 두 번째 오답 후 설명으로 배운 상황 수

이 결과는 해당 활동의 응답 요약이며, 장기적인 어휘 습득이나 말하기 능력을 평가하는 점수는 아닙니다.

## 실행하기

### 내 컴퓨터에서

`index.html`을 다운로드한 뒤 웹 브라우저로 열면 됩니다. 로컬 파일은 인터넷 연결 없이도 실행할 수 있습니다. 패키지 설치, 개발 서버, 빌드 작업은 필요하지 않습니다.

### GitHub Pages로

1. GitHub 저장소의 최상위 위치에 `index.html`을 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Source**에서 **Deploy from a branch**를 선택합니다.
4. 브랜치를 **main**, 폴더를 **/ (root)**로 지정하고 저장합니다.
5. 배포가 완료되면 Pages 화면에서 사이트 주소를 확인합니다.

자세한 안내: [GitHub Pages 게시 소스 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

이 `README.md`는 `index.html`과 같은 위치에 올리면 됩니다. 앱 실행에 필요한 파일은 `index.html` 하나뿐입니다.

## 기술 구성

- **HTML:** 안내, 문항, 결과 화면
- **CSS:** 화면 너비에 대응하는 레이아웃, 버튼 및 피드백 스타일
- **Vanilla JavaScript:** 문항 표시, 응답 판정, 재도전, 진행 상태 및 결과 집계
- **Inline SVG:** 외부 이미지 파일 없이 표시하는 공통 그림

외부 라이브러리, 외부 API 호출, 데이터베이스, 로그인 시스템을 사용하지 않습니다. 오디오나 음성 인식 기능은 포함하지 않습니다. 각 상황의 그림은 같은 공통 그림을 사용하며, 상황별로 하단 설명이 바뀝니다.

기본적인 키보드 버튼 조작, 포커스 표시, 피드백의 `aria-live` 알림을 구현했습니다. 별도의 접근성 적합성 인증이나 종합 검증을 의미하지는 않습니다.

## 응답 데이터

앱은 이름이나 계정 정보를 입력받지 않습니다. 응답 집계는 현재 열린 페이지의 메모리에서만 유지하며, 앱 코드가 이를 서버로 전송하거나 브라우저 저장소에 기록하지 않습니다.

새로고침하거나 페이지를 닫으면 진행 상태와 결과가 사라집니다. 교사용 결과 수집, 학생별 기록, 이어하기 기능은 없습니다.

## 문항 수정하기

`index.html`의 `<script>` 안에 있는 `items` 배열에서 내용을 수정할 수 있습니다.

| 필드 | 내용 |
| --- | --- |
| `title` | 문항 제목 |
| `scene` | 그림 아래의 상황 설명 |
| `context` | 상황 또는 활동 안내 |
| `sentence` | 영어 문장; `<strong>`으로 목표 표현 강조 |
| `options` | 세 가지 선택지 |
| `answer` | 정답 선택지의 인덱스: 첫 번째 `0`, 두 번째 `1`, 세 번째 `2` |
| `hint` | 첫 오답 후 제공할 힌트 |
| `explain` | 정답 확인 또는 두 번째 오답 후 제공할 설명 |

문항 수를 바꾸면 `items`뿐 아니라 HTML의 진행 막대 `max` 값과 “6가지 상황”, “여섯 가지 상황” 같은 안내 문구도 함께 수정해야 합니다.
